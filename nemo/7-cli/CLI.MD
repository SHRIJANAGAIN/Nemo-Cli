## Overview

This module tracks the CLI build history, bugs, and auto-repair actions.

## Build History

- v0.1.0: Initial release with basic tools
- v0.2.0: Added MCP, Skills, Memory
- v0.3.0: Added nemo-style UI, themes, shortcuts

## Auto-Repair

Run `autorepair.ts` to automatically fix common CLI bugs.

## Reinstall

Run `reinstall.ts` to reinstall NEMO from scratch.

## Reset

Run `reset.ts` to reset NEMO to factory settings.

## Bug Tracking

All bugs are logged in `nemo/1-errors/` and tracked via `clibugs.py`.
