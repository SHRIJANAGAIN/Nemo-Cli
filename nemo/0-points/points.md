# Shrijan - Points System

# Points are awarded to the assistant for successful task completion

## Point Values by Task Type

| Task Type | Points |
| --------- | ------ |
| Easy      | +1     |
| Normal    | +3     |
| Medium    | +5     |
| High      | +10    |
| Critical  | +20    |

## Bonus

- First try success: +2 bonus
- No errors: +1 bonus
- User positive feedback: +3 bonus

## Penalty

- Repeated mistake: -5
- Hallucination: -10
- User correction needed: -3
