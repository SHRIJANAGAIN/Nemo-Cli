# MCP Install

Install and manage MCP servers.

## Actions

- /mcp search <query> - Search for available MCP servers
- /mcp install <server-id> - Install an MCP server
- /mcp list - List all available MCP servers
- /mcp info <server-id> - Show details for a server

## Examples

- /mcp search filesystem - Find filesystem MCP servers
- /mcp install nemo-git - Install Nemo Git MCP server
- /mcp list - Show all available servers
