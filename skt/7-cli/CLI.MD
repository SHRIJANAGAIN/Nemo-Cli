## Auto-Repair

Run `autorepair.ts` to automatically fix common CLI bugs.

## Reinstall

Run `reinstall.ts` to reinstall TRAYAMBAK from scratch.

## Reset

Run `reset.ts` to reset TRAYAMBAK to factory settings.

## Bug Tracking

All bugs are logged in `skt/1-errors/` and tracked via `clibugs.py`.
